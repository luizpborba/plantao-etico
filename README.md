# Plantão Ético

Jogos para estudar a ética da Psicologia, feitos para o celular.

- **[Primeira Semana de Plantão](https://luizpborba.github.io/plantao-etico/)**: jogo narrativo. Você vive duas semanas de plantão, conversa com pacientes e colegas, faz a Prova do CRP, simula atendimentos em casos clínicos hipotéticos e decide cada caso com a supervisão da Helena.
- **[Modo treino](https://luizpborba.github.io/plantao-etico/treino.html)**: quiz com as questões da disciplina, casos práticos, desafio do dia, missões e simulado.

O progresso fica salvo no navegador de cada pessoa. Conteúdo educativo baseado no Código de Ética Profissional do Psicólogo (Resolução CFP nº 010/2005) e em resoluções do Conselho Federal de Psicologia. Personagens fictícios.

## Como publicar

Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
